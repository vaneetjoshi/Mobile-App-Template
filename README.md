# Mobile App template

Template that the central builder compiles into a tenant's Android app (GitHub Actions `build.yml`).

One-time setup (creates package.json and package-lock.json with versions that match each other):

    npx create-expo-app@latest tmp --template blank
    cp tmp/package.json tmp/package-lock.json .
    npm install
    npx expo install react-native-webview expo-splash-screen
    rm -rf tmp

Keep `App.js`, `index.js`, `app.base.json`, `scripts/` and `.github/workflows/build.yml`. `index.js` is required: package.json `main` points to it. Commit package-lock.json (the workflow runs `npm ci`).

The workflow expects `app-config.json` placeholder to exist for local runs only; it is generated by `scripts/prepare.js` during a build.

Laravel side (.env): MOBILE_APP_GITHUB_TOKEN (fine-grained token, Actions: read and write on this repo), MOBILE_APP_GITHUB_REPO (owner/repo).
